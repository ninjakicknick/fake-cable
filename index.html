How “live” works

Schedules are generated deterministically from the lineup and reset at midnight Eastern Time. Viewers with the same station content should get the same programming at the same moment, wherever they are.

The guide

The vertical marker shows the current time. Program titles stay visible while you scroll horizontally, and Tune returns directly to the channel playing now.

Your lineup

Fake Cable begins with five curated stations. Add individual stations or combine several into a custom mix. A mix can replace its sources in the guide while keeping them editable in Settings.

Commercial breaks

Fresh installs include classic commercials between programs. Open Settings to turn them off or use a different YouTube playlist. Commercials play without program banners or upcoming-program announcements.

Phone remote

Pair a phone to navigate, tune directly, view program information, toggle closed captions, mute playback, or search for new channels. No account or app download is required.

Install

If your browser supports app installation, use Install App on the opening screen. Playback, pairing, and channel refreshes still require internet access.

If something goes wrong

Refresh a channel from Settings. Unavailable videos are skipped automatically without looping. If YouTube temporarily fails, Fake Cable keeps the last working programming.
