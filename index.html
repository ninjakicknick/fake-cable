How “live” works

Each station gets a clock-driven daily schedule. Tuning in starts the current video at the point it would have reached if the station had been playing all day.

Your lineup

Channels are saved only in this browser. Clearing its data removes them. Use Share Lineup to copy your stations to another device or create a recovery link.

Install

If your browser supports app installation, use Install App on the opening screen. Playback and channel refreshes still require internet access.

If something goes wrong

Refresh a channel from Settings. Unavailable videos are skipped automatically. If YouTube temporarily fails, Fake Cable keeps the last working programming.
